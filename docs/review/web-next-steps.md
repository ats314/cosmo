**The verified reliability defects are concrete and separable from that visual work.** The following reproductions evaluated current source with in-memory storage and intercepted requests. No production accounts, scores, or telemetry were written.

- **Concurrent cloud saves can regress progress.** [progress.mjs](C:/COSMO/netlify/functions/progress.mjs:43) reads a document, merges it, then overwrites it. Strong consistency does not serialize this sequence. Two simultaneous proposals of best `300` and `200` finished with stored best `200`; a learned-set member also disappeared. Use atomic conditional updates with retry, or a storage model that provides equivalent concurrency guarantees. Test interleavings, not only the pure merge function.
- **Restored sessions do not reconcile the whole save.** [cloudPull](C:/COSMO/src/game/runtime.js:3856) assigns the server document without calling the fuller adoption routine; [loadPrefs](C:/COSMO/src/game/runtime.js:3736) reads only selected asynchronous keys. With local best `300` and server `100`, restoration sent only GET and never uploaded `300`. Reversing them displayed `300` while disk remained `100`. Cloud `groove`, `hopped`, and `seen` were not adopted. Failed [cloud writes](C:/COSMO/src/game/runtime.js:3866) are swallowed without a durable retry queue. Reconciliation must preserve local-first play and work after reload, reconnection, and sign-out.
- **The first pageview disappears.** [Initialization](C:/COSMO/src/game/runtime.js:4346) calls `track` before `SWIPE_MODE` is initialized; the tracker reads it at line 4319 inside a swallowed exception. The probe emitted zero startup events, then emitted normally after initialization. Fix ordering and assert an intercepted payload before using visit-based funnels to evaluate the new direction.
- **Transfer codes can redeem more than once.** [auth.mjs](C:/COSMO/netlify/functions/auth.mjs:66) performs separate read and delete operations. Two simultaneous redemptions both returned success. Deletion errors are also swallowed before credential issuance. Make consumption atomic and fail closed; preserve the owner's deliberate passwordless experience.

There are currently no direct cloud-library/account-flow harnesses. The real [browser check](C:/COSMO/tools/enginecheck.mjs:70) intentionally blocks external requests, so its success cannot validate accounts. The leaderboard's separate single-blob race is explicitly accepted in [scores.mjs](C:/COSMO/netlify/functions/scores.mjs:99); reconsider it if use grows, without treating a soft friends-and-playtest board as an anti-cheat system.

**Lifecycle, glow alignment, and delivery need targeted follow-through.** The architecture review reproduced front-menu audio returning after `runtimePause`: its one-time silence is followed by `bedTick` restoring the idle pad while frames continue. Give foreground state lasting authority over the audio owner and test menu, picker, and live-run interruptions separately.
